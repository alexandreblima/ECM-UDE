# Reproducibility of manuscript v3

Run commands from the repository root. Rendering times below are approximate
on a modern laptop and exclude environment setup. Figure rendering requires
Times New Roman; diagram compilation requires a LaTeX installation with
`standalone`, TikZ, and Circuitikz. Generated output is written separately
from the saved scientific results.

The scope table reports what this release can actually regenerate. A saved
summary is not an independent rerun from raw data. Some original fitting and
audit scripts retain checks against private historical commits or omitted
raw trajectories and are not claimed to be runnable from this release.

The saved results also include HG2 (E5), M50T (E5), and neural ablation (E6)
checkpoints and summaries. Their preregistration and amendments are recorded in
`REGISTRATION_LOG.md`; exploratory analyses are identified in their reports.
Full raw-data fits require the datasets in `DATA.md` and substantially more
time (typically hours for neural training). They are not validated as a
complete independent reproduction by the render commands above.

## Historical scripts with omitted dependencies

`python reviewer_saved_analysis.py --output /path/to/empty/directory`
regenerates the historical paired comparisons, training audit and E1 tables
without overwriting saved results or requiring the excluded
`results/variant_tost/` directory. Its 36 paired TOST records have been
checked against `results/reviewer_round2/D/tost_pvalues.csv`.

`report_reviewer_round.py` was removed from the release because it depended
on excluded private preservation archives; replacing its historical
preservation claims would require rewriting the report. The saved-summary
rendering commands above do not depend on it.

`exp_a123_temperature_interp.py` requires thermal trajectory NPZ files
containing measurements, which are not distributed. It checks for them
before starting and identifies `exp_a123_temperature.py` as the generator
from raw data. That script also overwrites saved thermal results, so run it
only in a disposable copy. The interpolation script's public-integrity
checks do not automatically accept newly generated files; regenerating the
trajectories alone does not establish a validated end-to-end rerun.
